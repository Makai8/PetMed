# PetMed – Sprint 2: Data Dictionary

## 1. USER

Description: Stores the account for each person using PetMed.

| Field Name | Description | Data Type | Key | Required | Allowed Values / Constraints |
| --- | --- | --- | --- | --- | --- |
| user_id | Unique identifier for a user. | INT UNSIGNED | PK | Yes | Auto-increment |
| role_id | Role assigned to the user. | INT UNSIGNED | FK → ROLE.role_id | Yes | Must reference an existing role |
| email | User's email/login address. | VARCHAR(255) | UNIQUE | Yes | Valid email; unique across users |
| password_hash | Secure password hash; never store a plaintext password. | VARCHAR(255) | None | Yes | Password hash generated by the authentication system |
| display_name | Name displayed to other users. | VARCHAR(100) | None | Yes | Non-empty text |
| status | Current account state. | VARCHAR(20) | None | Yes | active, suspended, deactivated (confirm with team) |
| created_at | Date and time the account was created. | DATETIME | None | Yes | Valid date/time; default CURRENT_TIMESTAMP recommended |

## 2. ROLE

Description: Defines the role assigned to a user.

| Field Name | Description | Data Type | Key | Required | Allowed Values / Constraints |
| --- | --- | --- | --- | --- | --- |
| role_id | Unique identifier for a role. | INT UNSIGNED | PK | Yes | Auto-increment |
| role_name | Unique role name. | VARCHAR(40) | UNIQUE | Yes | pet_owner, veterinarian, pet_health_expert, community_moderator, administrator (confirm naming) |

## 3. PERMISSION

Description: Defines an application permission.

| Field Name | Description | Data Type | Key | Required | Allowed Values / Constraints |
| --- | --- | --- | --- | --- | --- |
